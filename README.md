##  Repository Overview
This repository contains all lab submissions, tasks, and coursework for the Data Visualization module.
Each week focuses on foundational principles of visual data analysis, perceptual encoding, statistical charting, and chart design using Python.

---

##  Weekly Assignments Breakdown

### 🔹 Week 1: Core Visualization Principles
* **File:** `Week1.ipynb`
* **Focus:** Fundamental rules of chart selection, data-ink ratio, and objective-driven visualization.
* **Datasets Used:** `datasaurus.csv`, `flights.csv`, `gapminder.csv`, `mpg.csv`, `penguins.csv`
* **Key Deliverables:** 
  - Standardized chart structures adhering to zero-baseline rules for bar charts.
  - Selective labeling and elimination of dual y-axes.
  - Insight-driven figure titles and markdown explanations for visual choices.

---

### 🔹 Week 2: Visual Perception & Cognitive Processing
* **File:** `Week2.ipynb`
* **Focus:** How the human brain processes visual stimuli, preattentive attributes, Gestalt principles, and cognitive load management.
* **Datasets Used:** `stimuli_search.csv`, `stimuli_gestalt.csv`, `car_crashes.csv`, `tips.csv`, `channel_trials.csv`, `iris.csv`, `gapminder.csv`, `diamonds.csv`
* **Key Deliverables:**
  - Experimental analysis of search response times and stimulus feature detection.
  - Evaluation of preattentive channels (color vs. shape) and Gestalt grouping.
  - Detailed perceptual justification cells accompanying each figure.

---

### Week 3: Matplotlib & Seaborn Architecture
* **File:** `Week3_`
* **Focus:** Deep dive into Matplotlib object-oriented plotting, Seaborn statistical interfaces, chart rebuilding, and Lie Factor analysis.
* **Datasets Used:** `case01_helmet_rickshaw.csv`, `case02_chai_quizzes.csv`, `case03_aqi_monitors.csv`, `case04_quartet_depts.csv`, `case05_same_stats_shapes.csv`, `case06_sensor_matrix.csv`, `case07_dual_axis_series.csv`, `case07_lie_factor.csv`, `vitals_10k.csv`, `ward_los_wide.csv`
* **Key Deliverables:**
  - Dissection and complete rebuild of misleading and poorly formatted charts.
  - Analysis of Anscombe's quartet variants and graphical integrity metrics.
  - Complex multi-variable statistical visualization using subplots and facet grids.
